# Caesar Cipher (C)

C로 구현한 시저 암호(Caesar cipher) 프로그램입니다. 입력한 메시지를 지정한 칸 수만큼 밀어 암호화한 뒤, 같은 키로 다시 복호화해 보여줍니다.

## 동작 방식

- 알파벳 대문자(`A–Z`)와 소문자(`a–z`)만 이동시키고, 공백·숫자·한글·기호는 그대로 둡니다.
- 암호화: 각 글자를 `shift`칸 뒤로 이동 (`Z` 다음은 `A`로 순환)
- 복호화: `26 - shift`칸 이동해 원래 글자로 되돌림

예) `shift = 3` → `Hello World` ⇄ `Khoor Zruog`

## 빌드 및 실행

```bash
gcc -o caesar Caesar_cipher_using_C.c
./caesar
```

## 실행 예시

```
암호화할 메시지를 입력하세요: Hello World
암호화할 횟수(숫자)를 입력하세요: 3
암호화된 메시지: Khoor Zruog
복호화된 메시지: Hello World
```

## 참고

- 이동 값은 **1–25** 사이를 사용하세요. 음수나 26보다 큰 값은 복호화 결과가 올바르지 않을 수 있습니다.
- 메시지는 최대 99자까지 입력됩니다.
